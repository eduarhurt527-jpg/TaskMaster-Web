# Recursos visuales

## Identidad TaskMaster

- `assets/img/branding/taskmaster-mark.svg`: isotipo original creado para este proyecto. Combina la inicial T con una marca de verificación. Colores definidos por el sistema visual de TaskMaster.
- `assets/img/integrations/onedrive.svg` y `teams.svg`: representaciones SVG locales creadas para identificar visualmente las integraciones de Microsoft dentro del prototipo académico.

## Iconos de servicios

Los SVG de Google, Brevo y calendarios que ya estaban en `integraciones/public/assets/icons/` se reutilizan localmente. No se realizan solicitudes a CDN durante la navegación.

## Fuentes y licencias recomendadas

- [Lucide Icons](https://lucide.dev/): iconos de interfaz, licencia ISC.
- [Simple Icons](https://simpleicons.org/): referencia para marcas. La disponibilidad de cada logo no implica permiso de uso de la marca; deben respetarse las directrices del propietario.
- [unDraw](https://undraw.co/): ilustraciones SVG gratuitas bajo los términos publicados por unDraw.

No se añadieron fotografías de terceros ni imágenes incrustadas en base64.
